# Provenance — prompt-engineering

Pages in this module are authored manually against the official sources in
`source-registry.md`, with current documentation fetched via Context7 at authoring time
(`/websites/platform_claude_en`). Per-page provenance stubs and front-matter fields
record what was checked and when.

Provider and model behavior claims appear only where they trace to those official
pages. Practice patterns for agents, tools, and verification are labeled as craft
guidance and are not presented as vendor guarantees. No private transcripts, personal
paths, repository identities, or individual usage data appear in this module, and no
single person's usage is presented as representative practice.
