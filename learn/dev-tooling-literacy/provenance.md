# Provenance — dev-tooling-literacy

Pages in this module were drafted by a non-Claude model against official sources
fetched via Context7 at authoring time, then fact-checked by a reviewer against those
sources before landing. Each page's front matter records its sources, the Context7
library and queries used (where applicable), and when it was last checked; each page's
own Provenance section states how it was produced.

Vendor and tool behavior claims appear only where they trace to the official pages in
`source-registry.md`. Practice patterns are labeled as practice guidance and are not
presented as vendor guarantees; where a cross-tool claim could not be verified, the page
says so. No private transcripts, personal paths, repository identities, or individual
usage data appear in this module.
