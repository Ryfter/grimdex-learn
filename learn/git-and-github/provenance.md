# Provenance — git-and-github

Pages in this module are authored manually against the official sources in
`source-registry.md`, with current documentation fetched via Context7 at authoring time.
Per-page provenance stubs and front-matter fields record what was checked and when.

Command patterns were selected for teaching value from general practice with these
tools. No private transcripts, personal paths, repository identities, or individual
usage data appear in this module, and no single person's usage is presented as
representative practice.
